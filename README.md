# Signage

A small, self-hostable digital signage system. Screens (TVs with a browser, or a mini-PC/Raspberry Pi)
show a carousel of slides (images, videos, web pages, HTML), managed from one web admin. It runs as one
container plus PostgreSQL.

> 🚧 Under construction: Milestone 1 is in development. The quick start, configuration and screenshots
> arrive with WP-12. See `docs/PROJECT_BRIEF.md` for the scope.

**Security note:** Signage expects to run on a trusted network behind your firewall. Don't expose it
to the public internet.
